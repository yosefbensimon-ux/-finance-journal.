# לוח הבקרה הפיננסי — הוראות הקמה

אפליקציית ווב מלאה (React + Supabase) עם התחברות משתמשים ושמירת נתונים אמיתית בענן.

## שלב 1: יצירת חשבון וטבלאות ב-Supabase (חינמי)

1. גשו ל-https://supabase.com ולחצו "Start your project" → הירשמו (אפשר עם Google).
2. לחצו "New project". תנו שם (למשל `finance-journal`), בחרו סיסמה למסד הנתונים (שמרו אותה בצד), ובחרו אזור קרוב (למשל Europe).
3. חכו כ-1-2 דקות שהפרויקט יוקם.
4. בתפריט הימני: **SQL Editor** → **New query**.
5. פתחו את הקובץ `supabase-schema.sql` מהתיקייה הזו, העתיקו את כל התוכן, הדביקו בעורך, ולחצו **Run**.
6. בתפריט הימני: **Project Settings** (גלגל שיניים) → **API**.
   - העתיקו את **Project URL**
   - העתיקו את **anon public** key

## שלב 2: חיבור הקוד למסד הנתונים

1. בתיקיית הפרויקט, העתיקו את הקובץ `.env.example` לקובץ חדש בשם `.env`.
2. פתחו את `.env` והדביקו את הערכים שהעתקתם:
   ```
   VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```

## שלב 3: הרצה מקומית (לבדיקה במחשב שלכם)

דרוש [Node.js](https://nodejs.org) מותקן (גרסה 18 ומעלה). לאחר מכן, בתיקיית הפרויקט:

```
npm install
npm run dev
```

האתר ייפתח בכתובת שתופיע בטרמינל (בדרך כלל http://localhost:5173). היכנסו עם "הרשמה" ליצירת המשתמש הראשון שלכם.

## שלב 4: פרסום לאינטרנט עם Vercel (חינמי)

**האפשרות הפשוטה ביותר — גרירה ושחרור:**

1. הריצו בתיקיית הפרויקט: `npm run build` — זה ייצור תיקיית `dist`.
2. גשו ל-https://vercel.com והירשמו (אפשר עם GitHub/Google).
3. לחצו "Add New" → "Project" → יש אפשרות "Deploy" עם גרירת תיקייה — גררו את תיקיית `dist`.
4. **חשוב:** ב-Vercel, תחת Project Settings → Environment Variables, הוסיפו את אותם שני משתנים (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`) ואז בצעו Redeploy — כי אתר סטטי שנבנה מראש "אופה" את המשתנים בזמן ה-build, אז חשוב שיהיו מוגדרים גם ב-Vercel לפני הבנייה שם.

**האפשרות המומלצת בטווח הארוך — חיבור ל-GitHub:**

1. העלו את התיקייה הזו ל-repository חדש ב-GitHub.
2. ב-Vercel: "Add New" → "Project" → "Import" מה-GitHub repo שלכם.
3. הוסיפו את משתני הסביבה (כמו למעלה) במסך ההגדרות לפני הלחיצה על Deploy.
4. מעכשיו, כל שינוי שתדחפו ל-GitHub יתפרסם אוטומטית.

## מבנה הפרויקט

```
src/
  main.jsx          נקודת הכניסה
  App.jsx           שער התחברות — מציג Auth או את האפליקציה
  Auth.jsx           מסך כניסה/הרשמה
  FinanceJournal.jsx  האפליקציה עצמה (תנועות, יומן, קטגוריות, תזכורות, דוחות)
  supabaseClient.js   חיבור ל-Supabase
supabase-schema.sql   סכמת מסד הנתונים - להרצה חד-פעמית ב-Supabase
```

## מה כלול

- התחברות/הרשמה עם אימייל וסיסמה, כל משתמש רואה רק את הנתונים שלו (Row Level Security)
- הוספת הכנסות/הוצאות עם כל השדות המפורטים (צ'ק, אסמכתא, סטטוס, תשלומים...)
- ניהול לקוחות/ספקים/קבלני משנה/עובדים עם השלמה אוטומטית בטופס
- יומן שבועי צבעוני, גרף לפי קטגוריה, קטגוריות עם צבע לבחירה
- תזכורות עם חזרתיות ונודניק
- דוח מטריצת לקוחות/ספקים

## מה עוד לא ממומש (לשלב הבא)

- תצוגות יומי/חודשי/שנתי (רק שבועי פעיל כרגע)
- צירוף קבצים/קבלות
- תקציב חודשי והתראות חריגה
- ייצוא לאקסל/CSV
- התראות דחיפה בפועל (נודניק כרגע נשמר כהגדרה, ללא push notifications אמיתיות — זה ידרוש שירות נוסף)
